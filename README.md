# portfolio

My personal site — projects and GitHub contributions.

Live at [govindvashishat.me](https://govindvashishat.me).

## Stack

- Next.js + Tailwind
- Hosted on Vercel

## Local development

```bash
npm install
npm run dev
```

Site: http://localhost:3000

## Content

- **Projects** — edit `src/lib/projects.ts`

## Deploy

Push to `main`. Vercel rebuilds.
